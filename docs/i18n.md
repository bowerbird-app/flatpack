# Kit copy and host languages

FlatPack ships English defaults for kit chrome (buttons, empty states, aria labels, and the rest) under the `flatpack.*` I18n namespace. The gem does **not** ship French or any other language. The host app owns languages, locale selection, and translations.

## What the gem provides

- `config/locales/flatpack.en.yml` — English strings under `flatpack.*`
- `FlatPack::Copy.t` / `fp_t` / `fp_text` — components read omitted string props from I18n
- `flat_pack_copy_data` — JSON for `data-fp-copy` on `<html>` so Stimulus follows the current locale
- `flat_pack/copy.js` — `flatPackCopy(key)` with English fallbacks if the payload is missing

An explicit component prop still wins, including `nil` when that hides a label.

## What the host provides

1. Copy `flatpack.en.yml` into the host as `config/locales/flatpack.<locale>.yml`.
2. Translate the values. Keep the same keys. Interpolation tokens such as `%{count}` stay in the string.
3. Choose languages in the host (for example with [RecordingStudio_Internationalization](https://github.com/bowerbird-app/RecordingStudio_Internationalization)). FlatPack does not select locales.

Example host file:

```yaml
fr:
  flatpack:
    skip_link:
      text: Aller au contenu
    password:
      show: Afficher le mot de passe
      hide: Masquer le mot de passe
```

## Layout

```erb
<html
  lang="<%= I18n.locale %>"
  <%= tag.attributes(data: flat_pack_copy_data) %>
>
```

If the host already uses `recording_studio_locale_attributes`, merge the copy payload into the same `data:` hash.

Rerun `rails generate flat_pack:install` after upgrading so `flat_pack/copy` is pinned.

## Dummy demo

The Rails 8 dummy app is a host. It adds `recording_studio_internationalization`, `test/dummy/config/locales/flatpack.fr.yml` covering every gem English key, and `recording_studio_language_selector` in the catalog top nav immediately left of the theme control. Catalog full-page HTML cache keys include the current locale so a French visit does not reuse English HTML. `test/dummy-rails-7` does not use that gem.

The internationalization gem’s missing/export tasks scan `recording_studio.*` only. They will not list `flatpack.*` keys. Coverage for host translations is a host concern (the dummy test checks that dummy French covers gem English).
